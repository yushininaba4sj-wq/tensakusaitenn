# GOUKAKULINK ロゴ設置手順（本体サイト用・友達へ渡す）

- 作成日: 2026-06-10
- 担当部門: 技術担当（ロゴデザイン＝マーケティング担当）
- ねらい: 「先輩リンク（SENPAI LINK）」と**姉妹感のある GOUKAKULINK ロゴ**を、本体サイト（goukakulink.vercel.app）の**ヘッダー**と**ファビコン（ブラウザのタブに出る小さいアイコン）**に設置する。
- 確認済みの前提: 本体サイトは **Next.js（App Router）** で動いている。現状ファビコンは `app/favicon.ico`（256×256）、Appleアイコン（iPhoneホーム追加用）は未設定。

> 先輩リンク本体には「緑の六角形＋ペン先」ロゴが入っています。今回のGOUKAKULINKロゴは**同じ構図の赤バージョン**＝姉妹ブランドとして揃えています。

| ファイル | 中身 | サイズ/形式 | 主な用途 |
|---|---|---|---|
| `goukakulink-logo.png` | フルロゴ（六角形＋ペン＋「GOUKAKU LINK」の文字） | 1024×1024・透過PNG | LP・OGP画像・大きく見せたい所 |
| `goukakulink-mark.png` | **マークのみ**（文字なし・六角形＋ペン） | 640×640・透過PNG | ヘッダーのロゴアイコン |

## ① ファビコン（タブのアイコン）を差し替える ★必須

Next.js（App Router）なので、**`app/` フォルダにファイルを置くだけ**で `<link>` は自動生成されます。

1. 既存の **`app/favicon.ico` を、同梱の `favicon.ico` で上書き**する。
2. **`apple-icon.png` を `app/` に追加**する（iPhoneでホーム画面に追加したとき用。現状未設定なので入れておくと良い）。
3. （推奨）**`icon.png` も `app/` に追加**する。高解像なので高DPI画面でくっきり出る。
   - ※ `app/favicon.ico` と `app/icon.png` が両方あってもOK。Next.jsが両方リンクを出し、ブラウザが綺麗な方を選びます。

置いたあとの `app/` のイメージ:
```
app/
  favicon.ico      ← 差し替え
  icon.png         ← 追加（推奨）
  apple-icon.png   ← 追加
  layout.tsx
  ...
```
これで `git push`（or `vercel --prod`）すれば反映されます。**コードの追記は不要**（App Routerが自動でやってくれる）。

## ② ヘッダーにロゴを表示する

ヘッダーに「GOUKAKULINK」と**文字で出している**なら、その**左にマークだけ**を並べるのがきれい（フルロゴは文字が重複するのでヘッダーには使わない）。

1. `goukakulink-mark.png` を **`public/` フォルダ**に置く。
2. ヘッダーのコンポーネントで、サイト名の横に追加:

```tsx
import Image from "next/image";

// ヘッダーのロゴ部分（例）
<a href="/" className="flex items-center gap-2">
  <Image
    src="/goukakulink-mark.png"
    alt="GOUKAKULINK"
    width={32}
    height={32}
    priority
    className="h-8 w-8"
  />
  <span className="text-lg font-black tracking-tight">GOUKAKULINK</span>
</a>
```

- サイズはお好みで（`h-7`〜`h-9` あたりが目安）。
- 文字を出していない/ロゴだけにしたい場合は、`goukakulink-logo.png`（フル版）を使ってもOK。その場合 `<span>` の文字は消す。

---

## ③ 守ってほしいこと（ブランド維持）

- **背景は透過**。色を変えない／縦横比を崩さない（`width`と`height`は同じ比率に）／回転させない。
- ロゴの**まわりに余白**を確保（最低でもマークの高さの1/4ぶん）。
- 白背景でも暗い背景でも映えます（六角形が赤＋中央が白いペン）。
- 先輩リンク（senpailink.vercel.app）の緑ロゴと**ペアで揃える**意図。勝手にアレンジしないでください。

---

## ④ 反映チェック

1. デプロイ後、ブラウザのタブに**赤い六角形のアイコン**が出ればファビコンOK。
   - 出ないときはキャッシュが残っているだけ。ハードリロード（Ctrl+Shift+R）か、シークレットタブで確認。
2. ヘッダーに赤いマークが出ていればOK。

困ったら先輩リンク側（こちら）に聞いてください。ファビコン・ヘッダーどちらも10分かからず終わります。
