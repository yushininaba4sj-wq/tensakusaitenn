# 運営ログイン（OPERATOR_ALLOWED_EMAILS）設定

## 概要

`/admin/login` は **Vercel の `OPERATOR_ALLOWED_EMAILS` に載っているメールだけ** ログインできます。

- **未設定（空）:** ログイン画面は「未設定」表示で **誰も入れない**（安全側）
- **設定済み:** リスト内のメールのみ

## Vercel 設定

Project: `tensakusaitenn` → Settings → Environment Variables

| 変数名 | 例 | Environment |
|---|---|---|
| `OPERATOR_ALLOWED_EMAILS` | `you@gmail.com,friend@gmail.com` | Production（+ Preview 推奨） |

**推奨:** 最初は **2〜5件**、個人 Gmail（keio.jp 等の学校ドメインは卒業で失効するため非推奨）

設定後 **Redeploy** 必須。

## 運用ルール（月次）

1. **追加:** Vercel env にメールを足す → Redeploy
2. **削除:** 不要メールを env から外す → Redeploy（すぐ無効化）
3. **月1見直し:** 今も必要な人だけ残す
4. **引継ぎ:** 退任者は即削除、後任は個人 Gmail で追加

## 確認

1. https://goukakulink.vercel.app/admin/login
2. 許可メール → ログイン可
3. 未許可メール → 「運営用アカウントのみ」エラー
