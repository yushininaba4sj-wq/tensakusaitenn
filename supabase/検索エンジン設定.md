# 検索エンジン（Google）に載せる手順

## コード側（済み）

- `robots.txt` … 公開ページは許可、ログイン系は除外
- `sitemap.xml` … トップ + 各サービスページ
- メタタグ … `index, follow` + canonical + OGP
- 構造化データ … Organization / WebSite / FAQ / Service

## 1. Google Search Console に登録（必須）

1. https://search.google.com/search-console を開く
2. **プロパティを追加** → URL プレフィックス: `https://goukakulink.vercel.app`
3. 所有権確認 → **HTML タグ** を選ぶ
4. Vercel に環境変数を追加:
   - `GOOGLE_SITE_VERIFICATION` = meta の `content="..."` の値だけ
5. Redeploy 後、Search Console で「確認」
6. **サイトマップ** → `https://goukakulink.vercel.app/sitemap.xml` を送信

## 2. インデックスを促す

Search Console → **URL 検査** → `https://goukakulink.vercel.app` → **インデックス登録をリクエスト**

主要ページも同様:
- `/plan`
- `/tensaku`
- `/kakomon`
- `/qa`

## 3. 反映までの目安

- 数日〜2週間程度（新規サイトは遅れがち）
- 「GOUKAKU LINK」「合格リンク」などブランド名から先に出やすい

## 4. カスタムドメイン（任意・推奨）

独自ドメイン（例: `goukakulink.jp`）を Vercel に設定すると、検索での信頼性が上がりやすい。
